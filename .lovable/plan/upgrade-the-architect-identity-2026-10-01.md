# Upgrade The Architect Identity

## Goal
Upgrade the existing `the-architect` identity in place so Nexus and Aetheris post generators share one evidence disciplined, cross disciplinary personality without changing default behavior, models, tools, schemas, or visual settings.

## What will change
- Preserve the supplied full persona specification in a server only source artifact.
- Replace the current short identity prompt with a shared bounded policy builder that supports two contexts:
  - Nexus reasoning, advice, explanation, coding, negotiation, and supportive conversation.
  - Finished audience facing post generation with platform, topic, tone, length, privacy, and factual controls preserved.
- Encode selective use of psychology, philosophy, history, theology, AI, coding, and marketing without forcing every domain into every answer.
- Add disciplined analogy guidance: literal concept, familiar comparison, mapping, limit, and action; generally no more than one strong analogy in a short post.
- Preserve stable identity ID `the-architect`; unknown identities and unselected identity continue using the existing default voice.
- Route the shared post policy through Random Post and the other existing Architect persona path, removing duplicated browser or server persona definitions where practical.
- Keep Nexus tool rules, Golden Report money lock, confidentiality, factual boundaries, output schemas, generation and regeneration behavior unchanged.

## Validation
- Add regression tests for policy domains, analogy structure, Nexus versus post context, stable ID, unknown fallback, and prompt route wiring.
- Verify Random Post generation, length repair, draft persistence, library metadata, Nexus thread persistence, and regeneration retain the identity.
- Run targeted tests, full tests, type checking, and production build.
- Deploy only changed cloud functions; do not publish the website.
- Exercise a live request only if an authenticated or supported session is available; otherwise report the exact blocker.
