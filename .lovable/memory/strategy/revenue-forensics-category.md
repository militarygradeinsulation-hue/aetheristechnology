# The Move
Stop competing. Start categorizing. HubSpot didn't beat CRMs — they invented "inbound." Aetheris invents **Revenue Forensics**: a forensic investigation of where a business bleeds money, run through a live browser scanner nobody else has, with named leaks, dollar amounts, and specific fixes. Goal sentence from prospects: "I've never heard of anything like that."

# 5 Structural Moats (not positioning — actual unreplicable advantages)
1. **Live DOM Scanner** — sees the real, rendered, authenticated page. Static crawlers can't close this gap with a subscription.
2. **Competitor Teardown** — prospect runs it on a rival's site, sees rival's leaks. Self-selling demo. Makes the extension viral.
3. **Revenue Score (0–100)** — public, shareable standard only Aetheris can issue. Businesses display it. Prospects ask for it.
4. **Industry Leak Report** — aggregate leak intelligence from thousands of scans. Proprietary data, citation magnet, compounding moat.
5. **Leak Register** — living, versioned forensic document tracking found leaks + fix status + recovery $. Replaces the consulting deck. Client history doesn't transfer = retention.
