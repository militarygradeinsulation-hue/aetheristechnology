
# Forecast Center → Live, Educational, Admin-Configurable

Turn the Forecast Center from a fixed daily AI dump into a **live, educational intel feed** that pulls from:
- Aetheris's own articles, playbooks, and blog topics on the site
- The open web (Firecrawl search) — with admin-controlled topic queries
- Optional per-source live refresh (every X minutes, on-demand, or daily)

And give the admin a **widget-style "Forecast Settings" panel** to control everything without touching code.

---

## What changes for the user

### In the Portal (rep/partner view)
The Forecast Center gets two new sections + a refresh meter:
1. **Tip of the Day** *(existing)*
2. **Operator Education** *(new)* — "Read this today" cards pulled live from Aetheris's blog, playbooks, and pillar topics. Each card shows a 1-line *why this teaches you something useful today* explainer generated by AI.
3. **Tech Trends** *(existing)*
4. **Industry Shifts** *(existing)*
5. **Live Pulse** *(new)* — a thin strip at the top showing 3-5 just-in headlines (last 60 min) from configured topic feeds, auto-refreshed every N minutes. Click to expand.
6. **Target Companies** *(existing)*

Each rep sees a small **"Customize my view"** dropdown to toggle which sections they want, with their pick saved to localStorage. (Per-user, no DB.)

## Technical details

### New table: `forecast_settings` (single-row config)
- `id uuid pk`, `is_active bool`, `refresh_cadence_minutes int` (default 1440 = daily; min 30)
- `web_window text` ('h'|'d'|'w'|'m', default 'w')
- `topic_queries jsonb` — array of `{ id, label, query, enabled, industry? }` (seeded with current 5 + presets)
- `industry_presets jsonb` — array of `{ id, label, queries[] }` (Roofing, HVAC, Dental, Med Spa, Law, SaaS, Indy SMB, AI/CRM)
- `sources jsonb` — `{ aetheris_blog: true, aetheris_playbooks: true, web: true }`
- `sections jsonb` — `{ tip, education, tech, industry, live_pulse, companies }` booleans
- `education_pool jsonb` — array of `{ kind: 'blog'|'playbook'|'topic', id, title, enabled }`
- `live_pulse_minutes int` (default 15) — pulse refresh interval (client-side polling cap)
- `updated_at timestamptz`

Service-role only; admin endpoint exposes read/write.

### Extended table: `forecast_briefings`
Add columns:
- `education jsonb` — `[{ kind, title, url, why }]`
- `live_pulse jsonb` — `[{ title, url, source, ts }]`
- `settings_snapshot jsonb` — what config produced this run (for debugging)

### Edge functions

**`forecast-generate-daily`** (modified)
- Read `forecast_settings`. Bail early if `!is_active`.
- Build the search list from `topic_queries.filter(enabled)` instead of the hardcoded array.
- If `sources.aetheris_blog` or `sources.aetheris_playbooks`, query the existing tables (`blog_posts`, `playbooks` — discover at build time) for last 14 days of content + the `education_pool` whitelist.
- Pass all that as context to Gemini with an extended tool schema that adds `education[]` and `live_pulse[]`.
- Use `tbs: 'qdr:' + web_window` for Firecrawl.
- Honor `refresh_cadence_minutes` instead of the hard 24h cache: skip if last run age < cadence (unless `?force=true`).

**`admin-forecast-settings`** (new) — admin token gated
- Actions: `get`, `update` (full replace of jsonb config), `list_runs` (latest 10 from `forecast_briefings`), `seed_presets`.
- Reuses `verifyAdminToken` + service role.

**`portal-forecast`** (modified)
- `get_today` returns the new fields.
- New action `live_pulse` (lightweight, no AI) — fetches just the pulse list from today's row; called by client every `live_pulse_minutes`.

### Cron
Replace the daily 11:00 UTC job with a more frequent cron (e.g. every 15 min) that calls `forecast-generate-daily`. The function itself enforces `refresh_cadence_minutes` so admins control real frequency without a new cron each time. Insert via `supabase--read_query` insert tool (not migration).

### Frontend

**New** `src/components/admin/ForecastSettingsPanel.tsx` — the widget grid. Built from 6 small subcomponents:
- `MasterControlsWidget` (active toggle, cadence input, section switches)
- `TopicLibraryWidget` (list + add + remove + industry preset buttons; "Apply preset" merges queries)
- `SourceMixWidget` (toggles + web window select)
- `EducationPickerWidget` (multi-select chips for blog/playbook/topic IDs)
- `RunHistoryWidget` (table of last 10 runs + "Force regenerate today" button)
- `BriefingPreviewWidget` (renders `<ForecastCenter authMode="admin" isPartner />` inline)

**Modified** `src/pages/AdminDashboard.tsx` — Forecast tab swaps from raw `<ForecastCenter />` to `<ForecastSettingsPanel />`.

**Modified** `src/components/portal/ForecastCenter.tsx` — render new `Education` and `LivePulse` sections; respect per-user section visibility from localStorage; auto-poll `live_pulse` action every `live_pulse_minutes`.

**New** `src/lib/portalForecast.ts` additions — `getLivePulse()`, settings helpers.
**New** `src/lib/adminForecast.ts` — `getSettings`, `updateSettings`, `listRuns`, `forceRun`.

### Industry preset seeds (admin one-click)
- **Roofing** — "Indianapolis roofing storm damage news", "Indiana roofing license renewal trends"
- **HVAC** — "Indianapolis HVAC install hiring surge", "Indiana HVAC tax credit changes"
- **Dental / Med Spa** — "Indianapolis dental DSO acquisition", "Med spa Indiana opening"
- **Law** — "Indianapolis law firm hiring associates", "Indiana legal tech adoption"
- **SaaS** — "Indianapolis SaaS Series A funding", "Indy startup product launch"
- **AI / CRM** — current 2 queries
- **Indy SMB Pulse** — current Indy hiring/expansion query

Each preset is just a labeled bundle of `topic_queries` the admin can toggle on/off as a unit.
