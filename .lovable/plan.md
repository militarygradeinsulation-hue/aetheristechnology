## Phase 4 — Lead bank niche scraping

13. **Custom niche lead scraping** — new "Find Leads" panel inside `LeadsBoard`. Rep enters niche (e.g. "roofing companies") + location + count, picks source:
    - **RocketReach** (already connected) — search by industry/title/location.
    - **Firecrawl** — connect via `standard_connectors--connect`, scrape Google Maps / Yelp / industry directories.
    Results land in a staging list; rep one-clicks "Add to my Lead Bank" → inserts into `rep_leads`.
14. **Separate "Touches" tab** for all customer-contact activity (calls, emails, sms, meetings) — pulled from `mirror_engagements` + `rep_calendar_events` filtered to contact kinds. Replaces the mixed view in the current Activity tab.

---

## Phase 5 — Email warm-up automation (rep-approved)

15. **Automated lead warm-up emails (AI-drafted, rep approves each send).**
    - New table `rep_lead_warmup_drafts` (lead_id, rep_code, sequence_step, subject, body, status: pending_review/approved/sent/skipped, scheduled_for).
    - Edge function `generate-warmup-draft` uses Lovable AI + lead context (industry, website summary, last touch) to draft each touch.
    - Cron every 30 min: for any active lead with no touch in N days, generate next draft and queue for review.
    - New "Warm-Up Queue" panel in rep portal: rep sees stack of drafts → Edit / Approve & Send / Skip. Approved drafts send via existing rep mailbox infra.
    - Sequences: Day 0, Day 3, Day 7, Day 14, Day 30 (configurable per rep).
16. **Interview Briefing → Recruiting tool.** Surface the existing `InterviewBriefingPanel` outside admin so reps can use it to recruit/refer candidates. Generates a sharable briefing link + tracks who they sent it to.

- **AI model:** `google/gemini-2.5-flash` for drafts/posts (cheap, fast), `google/gemini-2.5-pro` for higher-value lead enrichment.
- All UI honors forensic identity: charcoal + amber, crimson reserved for leak/alert states, JetBrains Mono micro-labels.
