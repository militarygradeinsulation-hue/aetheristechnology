

# Professional Playbooks + Batch Generation + 2/Day Automation

## What's Happening Now
- 8 playbooks exist, generated from a pool of 18 topics (10 remaining)
- PDF generation uses jsPDF with basic dark-bg styling — functional but not polished
- Current cron runs once weekly (Mondays at 8 AM EST)

## Plan

### 1. Upgrade PDF Visual Quality
Rewrite the PDF rendering logic in `generate-playbook/index.ts` to produce a more professional document:
- **Cover page**: Add decorative geometric elements (lines, rectangles), larger amber accent bar, proper vertical spacing, page number footer on all pages
- **Table of contents**: Auto-generated from section headers on page 2
- **Section pages**: Each major section (##) starts on a new page with a decorative header bar and section number
- **Typography**: Increase body font to 11pt, better line spacing (6mm vs 5mm), wider margins
- **Tables**: Alternating row shading, proper cell padding, amber header row
- **Bullet points**: Indented with amber diamond markers instead of circles
- **Page footers**: "AETHERIS | Page X" on every content page
- **Back cover**: Branded CTA page with centered layout and contact info block

### 2. Generate 10 New Playbooks Immediately
Invoke the `generate-playbook` edge function 10 times sequentially (each call picks a random unused topic from the pool). This fills out the remaining topics.

### 3. Expand Topic Pool
Add 20+ new topics to the `TOPIC_POOL` array in `generate-playbook/index.ts` so the automated system has fuel for weeks. Topics will span all three pillars (Marketing Technology, Strategic Consulting, AI Transformation) and align with playground/recreation industry focus.

### 4. Change Cron to 2/Day
Update the `pg_cron` schedule from weekly to twice daily — 8 AM and 2 PM EST (matching the blog cadence). Each invocation generates one playbook, so two per day.

```text
Schedule: '0 12,18 * * *'  (UTC = 8AM, 2PM EST)
```

## Files Modified
- `supabase/functions/generate-playbook/index.ts` — PDF styling overhaul + expanded topic pool
- Database: new cron job via SQL insert (2/day schedule)

- The 10 initial playbooks will be generated by calling the edge function 10 times via `supabase--curl_edge_functions`
