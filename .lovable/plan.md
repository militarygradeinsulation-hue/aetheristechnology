

# Generate New Blog Posts + Retrofit Old Posts with 360 Brew Rules

## Overview
Two-part action: (1) trigger the edge function to generate several new blog posts using the current 360 Brew framework, and (2) create a one-time migration edge function that retrofits old blog posts with corrected tags, titles, and content structure.

## Part 1: Generate New Blog Posts (5-6 new posts)

Call the `generate-blog` edge function multiple times with specific high-value angles from each pillar to produce new posts that fully follow the 360 Brew framework. These will use the already-deployed prompt with proper semantic hooks, branded frameworks, data tables, and niche hashtags.

Suggested angles to generate:
1. **Pillar 1 (Marketing Tech)**: "Your pipeline report lies to you every Monday — here's how to build one that tells the truth"
2. **Pillar 1 (Marketing Tech)**: "You're A/B testing button colors while your funnel has a $200K hole in it"
3. **Pillar 2 (Consulting)**: "Your team uses Excel as a CRM because nobody trusts the $50K system you bought"
4. **Pillar 3 (AI)**: "You're invisible to ChatGPT, Gemini, and Perplexity — here's why that's killing your pipeline"
5. **Pillar 3 (AI)**: "B2B tech website traffic declined 34% and you're still optimizing for Google page 1 — the GEO shift"
6. **Pillar 2 (Consulting)**: "The integration tax: what disconnected systems really cost when you add up manual workarounds"

These will be generated by invoking the edge function with the specific angle and category in the request body.

## Part 2: Retrofit Old Blog Posts

There are ~124 existing posts. Many pre-date the 360 Brew update and have:
- Generic/broad hashtags (e.g., `AI`, `Leadership`, `Startups`, `#MachineLearning`)
- Titles that don't follow the `[Problem]: [Solution]` format
- Missing branded frameworks and semantic hooks
- Tags with `#` prefixes or branding tags that should be excluded

### Create a one-time edge function `retrofit-blogs/index.ts`
This function will:
1. Query all published blog posts
2. For each post, call the AI to:
   - Re-tag with 5 niche-specific hashtags from the correct pillar pool (no `#` prefixes, no branding tags)
   - Classify into the correct pillar and funnel stage
   - Generate a proper `meta_description` if missing or generic
3. Update each post's `tags` in the database
4. Process in batches to avoid timeouts

**Note**: We will NOT regenerate full content for all 124 posts (too expensive and would lose existing content). Instead, we fix **tags, meta descriptions, and location_focus** — the metadata that affects algorithm classification.

### For the ~10 oldest posts with the weakest structure
Optionally flag them for manual review or mark as unpublished if they significantly deviate from the brand voice.

## Technical Details

- **Edge function calls**: 6x `generate-blog` invocations with specific angles
- **New edge function**: `supabase/functions/retrofit-blogs/index.ts` — one-time batch tag/metadata updater
- **No frontend changes** — all backend/data operations
- **Database**: Updates to existing `blog_posts` rows (tags, meta_description fields)
